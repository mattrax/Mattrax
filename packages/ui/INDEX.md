# Components

One line per component in the shared UI package. Keep this list in sync when components are added or removed.

- Badge: status and categorization label. `packages/ui/src/badge`
- Button: action trigger. `packages/ui/src/button`
- Card: grouped content surface. `packages/ui/src/card`
- Cn: class name merging helper. `packages/ui/src/lib/cn`
- Controls: checkbox and switch inputs. `packages/ui/src/controls`
- Dialog: modal surface and parts. `packages/ui/src/dialog`
- DotMatrix: decorative dot grid. `packages/ui/src/dot-matrix`
- Feedback: alerts, breadcrumbs and empty states. `packages/ui/src/feedback`
- Filter: filter controls. `packages/ui/src/filter`
- FilterValues: filter value helpers. `packages/ui/src/filter-values`
- FilterWindowing: filter windowing helpers. `packages/ui/src/filter-windowing`
- HoverCard: hover preview surface. `packages/ui/src/hover-card`
- Icons: shared icon set. `packages/ui/src/icons`
- Input: text field. `packages/ui/src/input`
- LoadingState: loading and empty state helpers. `packages/ui/src/loading-state`
- Menu: dropdown menu parts. `packages/ui/src/menu`
- Page: page scaffolding. `packages/ui/src/page`
- PasswordInput: password field with visibility toggle. `packages/ui/src/password-input`
- Primitives: shared Kobalte wrappers. `packages/ui/src/primitives`
- Progress: progress indicator. `packages/ui/src/progress`
- SegmentedControl: segmented choice control. `packages/ui/src/segmented-control`
- Select: select control. `packages/ui/src/select`
- Sheet: slide-over surface. `packages/ui/src/sheet`
- Solid: SolidJS runtime helpers. `packages/ui/src/lib/solid`
- Spinner: loading spinner. `packages/ui/src/spinner`
- Table: data table parts. `packages/ui/src/table`
- Tabs: tabbed content. `packages/ui/src/tabs`
- Tooltip: hover and focus hint. `packages/ui/src/tooltip`
