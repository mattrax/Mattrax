# Docs

A bunch of assorted planning documentation for Mattrax.

### Self-hosting support

We need the following things to support self-hosting:
 - Built-in HTTPS
 - Storing logs (maybe rely on systemd)
 - Restrict open signup (Eg. require `@company.com` email)
 - Update system. Allow administrator to apply update via web interface.
 - Coordinate updates across cluster of Mattrax servers
