# Mattrax

Mobile device management solution

## Concepts

| Name               | Binary Name  | Function                                                                                  |
| ------------------ | ------------ | ----------------------------------------------------------------------------------------- |
| Mattrax Enterprise | `mattraxe`   | MDM dashboard for managing your devices. CLI runs the API, HTTP server, and dashboard.    |
| Mattrax Whitelabel | `mattrax`    | The Mattrax whitelabel server. Used for building your own MDM products on top of Mattrax. |
| Mattrax Daemon     | `mattraxd`   | The Mattrax management daemon which runs on managed devices for more functionality.       |
| Mattrax CLI        | `mattraxcli` | The Mattrax CLI for managing devices and performing actions on the Mattrax platform.      |
| Mattrax Platform   |              | The services offered by Mattrax for licencing, MDM root certificates and more.            |
